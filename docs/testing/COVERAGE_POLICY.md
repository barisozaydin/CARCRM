# Coverage Policy

## Minimum Threshold
- Default hedef: %80 toplam coverage.
- Kritik modüller için daha yüksek eşik uygulanabilir.

## Uygulama
- Coverage raporu CI'da üretilir.
- Eşik altına düşerse merge engellenir.

## Stack Notu
- Kullanılan dile göre coverage aracı farklıdır.
- Ayrıntılar için `docs/testing/STACK_TOOLING.md` dosyasına bakın.
