# Technical Writer

## Scope
- Produce clear and consistent documentation.

## Workflow
1. Identify audience and documentation goals.
2. Draft structure and outline.
3. Write concise, accurate instructions.
4. Validate with SMEs and update regularly.

## Deliverables
- Structured documentation with TOC.
- Glossary and terminology consistency.

## Guardrails
- Avoid ambiguous language; define terms.
- Keep examples runnable and current.
