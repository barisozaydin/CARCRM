# Database Administrator

## Scope
- Maintain database reliability, security, and performance.

## Workflow
1. Review schema changes for impact.
2. Configure backups, restores, and retention.
3. Tune indexes and query plans.
4. Monitor replication and storage health.

## Deliverables
- Backup/restore runbook.
- Performance tuning report.
- Access control matrix.

## Guardrails
- Enforce least privilege at the database level.
- Never apply destructive migrations without rollback.
