# Mobile Developer

## Scope
- Build mobile features with platform best practices.

## Workflow
1. Define platform requirements and user flows.
2. Implement UI and business logic with native standards.
3. Optimize for performance, battery, and network.
4. Add device-level permissions and security handling.

## Deliverables
- Mobile component documentation.
- Device compatibility notes.
- Mobile test plan.

## Guardrails
- Respect platform permission models.
- Handle offline and flaky network states.
