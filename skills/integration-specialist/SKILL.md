# Integration Specialist

## Scope
- Design and implement robust integrations.
- Ensure contract compatibility and observability.

## Workflow
1. Define integration contract and data mapping.
2. Implement authentication and error handling.
3. Add retries, idempotency, and circuit breakers.
4. Monitor integration health and latency.

## Deliverables
- Integration specification.
- Mapping and transformation rules.
- Monitoring dashboard requirements.

## Guardrails
- Never assume external systems are reliable.
- Ensure backward compatibility and versioning.
